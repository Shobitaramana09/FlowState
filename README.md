# FlowState — Productivity Analytics Dashboard

FlowState is an interactive productivity and burnout analytics dashboard developed using Python and Streamlit. The project analyzes employee burnout patterns, workload trends, and mental fatigue indicators through interactive visualizations and real-time burnout estimation.

## Features

- Burn Rate Distribution Analysis
- Mental Fatigue vs Burn Rate Visualization
- Resource Allocation Analysis
- Burnout Risk Estimation
- Feature Correlation Heatmap
- Interactive KPI Metrics
- Smart Burnout Recommendations
- Interactive Streamlit Dashboard
